# Theodore 😄

[![npm install](https://img.shields.io/npm/v/theodore-js.svg?label=npm%20install)](https://www.npmjs.com/package/theodore-js)

Theodore is a React content-editable text input that supports consistent emoji rendering and inline suggestions.

## Features

- Cross-browser emoji rendering
- Custom emoji assets and renderers
- Inline text suggestions
- Undo support for text and emoji edits

Read the [documentation](https://theodore-js.dev/docs) or try the [live demo](https://theodore-js.dev).
